全局事件总线。 纯 C\# 实现，独立于 Unity 生命周期，适用于任何需要事件通信的场景。 无单例模式，建议通过依赖注入或服务定位器访问。 遵循订阅-\/发布模式，用于模块间解耦通信。 所有公开方法均为线程安全（使用对象锁）。
