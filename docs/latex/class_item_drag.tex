\doxysubsection{详细描述}
物品拖拽组件 -\/ 处理可拖拽物品的\+UI交互 

功能说明：
\begin{DoxyEnumerate}
\item 支持拖拽物品图标在背包内移动
\item 实现三种目标交互：
\begin{DoxyItemize}
\item 与其他物品交换位置
\item 移动到空槽位
\item 拖出背包外丢弃物品
\end{DoxyItemize}
\item 拖拽失败时自动归位
\end{DoxyEnumerate}

实现接口：
\begin{DoxyItemize}
\item IBegin\+Drag\+Handler:\+ 开始拖拽
\item IDrag\+Handler:\+ 拖拽中
\item IEnd\+Drag\+Handler:\+ 结束拖拽
\end{DoxyItemize}

使用要求：
\begin{DoxyEnumerate}
\item 挂载在物品图标(\+Image)Game\+Object上
\item 父级必须是\+Slot对象
\item 需要\+Canvas\+Group组件支持射线遮挡控制 
\end{DoxyEnumerate}
