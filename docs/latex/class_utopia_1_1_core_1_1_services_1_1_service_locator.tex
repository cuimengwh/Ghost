\doxysubsection{详细描述}
线程安全、支持懒加载工厂的非单例服务定位器。 核心服务容器，提供服务的注册、解析和管理功能。 特性： 


\begin{DoxyEnumerate}
\item 线程安全：使用读写锁(\+Reader\+Writer\+Lock\+Slim)优化并发性能
\item 懒加载：支持通过工厂方法延迟创建服务实例
\item 非单例：可创建多个独立实例，适用于不同作用域
\item 生命周期管理：支持\+IDisposable服务的自动释放 
\end{DoxyEnumerate}
