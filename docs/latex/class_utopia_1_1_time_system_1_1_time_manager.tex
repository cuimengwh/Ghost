\doxysubsection{详细描述}
\doxylink{class_utopia_1_1_time_system_1_1_time_manager}{Time\+Manager} -\/ 负责游戏内时间的管理和事件系统 

功能说明：
\begin{DoxyEnumerate}
\item 管理游戏内的日期、时间、季节等状态
\item 支持时间缩放和暂停功能
\item 提供事件系统，允许其他系统订阅时间变化事件
\item 支持自定义日期时间结构，便于游戏内逻辑使用
\item 实现 ISaveable\+System 接口，支持存档/\+读档
\end{DoxyEnumerate}

使用要求：
\begin{DoxyEnumerate}
\item 挂载在场景中的单例\+Game\+Object上
\item 配置 \doxylink{class_utopia_1_1_time_system_1_1_time_settings}{Time\+Settings} Scriptable\+Object 以定义时间参数 
\end{DoxyEnumerate}
