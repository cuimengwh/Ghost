\doxysubsection{详细描述}
装备栏（快捷栏）管理器 

功能说明：
\begin{DoxyEnumerate}
\item 提供游戏内的快捷物品栏，直接引用背包前\+N个格子
\item 支持1-\/9数字键快速切换和选择物品
\item 单例模式实现，全局唯一访问点
\item 与背包数据实时同步，无独立存储
\end{DoxyEnumerate}

设计特点：
\begin{DoxyItemize}
\item 数据引用模式：直接引用背包数据，不单独存储
\item 快捷键支持：数字键1-\/9对应快捷栏1-\/9
\item 索引映射：快捷栏索引=背包前\+N个格子索引
\end{DoxyItemize}

使用要求：
\begin{DoxyEnumerate}
\item 需要关联到有效的\+Inventory背包
\item 背包必须有足够的格子数量（≥hotbar\+Size） 
\end{DoxyEnumerate}
