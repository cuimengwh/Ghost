详细描述

NPC管理器 NPC系统的核心实现类，负责：

  1. 加载和管理NPC的静态配置数据
  2. 加载、保存和管理NPC的运行时状态数据
  3. 提供NPC数据的查询和更新接口
  4. 协调配置数据和存档数据的合并

实现单例模式（通过服务定位器），作为NPC系统的中央数据枢纽
