详细描述

线程安全、支持懒加载工厂的非单例服务定位器。 核心服务容器，提供服务的注册、解析和管理功能。 特性：

  1. 线程安全：使用读写锁(ReaderWriterLockSlim)优化并发性能
  2. 懒加载：支持通过工厂方法延迟创建服务实例
  3. 非单例：可创建多个独立实例，适用于不同作用域
  4. 生命周期管理：支持IDisposable服务的自动释放

释放容器资源

执行以下操作：

  1. 释放所有实现IDisposable的服务
  2. 清空服务和工厂字典
  3. 释放读写锁
  4. 标记容器为已释放状态

注意：释放后容器不可再用。
