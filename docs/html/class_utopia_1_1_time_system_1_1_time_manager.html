详细描述

TimeManager - 负责游戏内时间的管理和事件系统

功能说明：

  1. 管理游戏内的日期、时间、季节等状态
  2. 支持时间缩放和暂停功能
  3. 提供事件系统，允许其他系统订阅时间变化事件
  4. 支持自定义日期时间结构，便于游戏内逻辑使用
  5. 实现 ISaveableSystem 接口，支持存档/读档

使用要求：

  1. 挂载在场景中的单例GameObject上
  2. 配置 TimeSettings ScriptableObject 以定义时间参数
