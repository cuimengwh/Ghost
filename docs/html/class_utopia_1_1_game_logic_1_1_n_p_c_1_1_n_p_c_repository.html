详细描述

NPC状态仓储的默认实现 使用IDataService进行实际的持久化操作

关键设计决策：

  1. 键名："npc_states"，修改会破坏向后兼容性
  2. 返回空字典而非null，简化调用方代码
  3. 通过构造函数注入依赖，支持不同存储实现
