成员函数说明

◆ GetSeason()

Season Utopia.TimeSystem.TimeSettings.GetSeason ( int month)
inline

根据月份获取对应的季节

参数
month月份（1~monthsPerYear）
返回
季节枚举

注意：原代码错误地将 month 限制在 [1, daysPerMonth] 范围内，已修正为 [1, monthsPerYear]。 季节与月份的对应关系为：1月→春，2月→夏，3月→秋，4月→冬。

◆ GetSunState()

SunState Utopia.TimeSystem.TimeSettings.GetSunState ( float time01)
inline

根据当天的时间进度（0-1）获取时段状态

参数
time010~1的小数，0=0:00，1=次日0:00
返回
太阳状态（早晨/中午/黄昏/午夜）

时段划分规则（与SunState枚举的Tooltip保持一致）：

  • 6:00 ~ 10:00 → Morn
  • 10:00 ~ 16:00 → Noon
  • 16:00 ~ 20:00 → Dusk
  • 20:00 ~ 次日6:00 → Midnight
